Aide et installation

  1. Connectez-vous avec Connexion EVE : la carte suit votre personnage et ajoute chaque système où vous sautez.
  2. Cliquez sur un système pour voir sa classe, ses statics, son effet, l'activité récente, vos notes et ses signatures.
  3. Dans le scanner du jeu, faites Ctrl+A puis Ctrl+C, et collez dans la zone Signatures du système.
  4. Cliquez sur une connexion pour indiquer le type de trou (ex. H296), la masse, la fin de vie, et utiliser le calculateur de masse.
  5. Notez chaque passage (« Ajouter un passage ») pour suivre la masse restante, partagée avec toute la corpo.
  6. Sorties vers le k-space : calcule le nombre de sauts vers Jita, Amarr, Dodixie, Rens, Hek et votre maison.
  7. Déplacez les systèmes à la souris, molette pour zoomer, cliquez-glissez le fond pour vous déplacer.

GitHub Pages héberge la carte gratuitement, à une adresse https. Votre PC n'a pas besoin de rester allumé.

  1. Créez un compte gratuit sur github.com.
  2. Cliquez sur + en haut à droite, puis New repository. Nom : carte-wh. Cochez Public, puis Create repository.
  3. Cliquez sur uploading an existing file, déposez le fichier carte-wh.html renommé en index.html, puis Commit changes.
  4. Allez dans Settings, puis Pages. Sous Branch, choisissez main et / (root), puis Save.
  5. Après une minute, votre carte est en ligne à l'adresse https://VOTRE-PSEUDO.github.io/carte-wh/.
  6. Mettez cette adresse comme Callback URL dans votre application EVE (onglet « Application EVE »).

Le dépôt est public : n'y mettez que ce fichier. Il ne contient aucun mot de passe, et le lien de votre base n'est jamais écrit dedans.

Deux services gratuits : Firebase (Google) stocke les cartes, Cloudflare vérifie l'identité des joueurs auprès de CCP. Aucune carte bancaire n'est demandée. Comptez 20 à 30 minutes, une seule fois.

A. Firebase

  1. Sur console.firebase.google.com, créez un projet (ex. petit-poucet). Google Analytics : inutile.
  2. Menu Créer (Build) → Authentication → Commencer. N'activez aucun fournisseur : ce n'est pas nécessaire.
  3. Menu Créer → Realtime Database → Créer une base de données. Emplacement : Belgique (europe-west1), mode verrouillé.
  4. Onglet Règles : remplacez tout par les règles ci-dessous, puis Publier.
{
  "rules": {
    ".read": false,
    ".write": false,
    "maps": {
      "$owner": {
        "ownerName": {
          ".read": "auth != null && ($owner === auth.uid || root.child('maps').child($owner).child('acl').child(auth.uid).exists())",
          ".write": "auth != null && $owner === auth.uid"
        },
        "acl": {
          ".read": "auth != null && ($owner === auth.uid || data.child(auth.uid).exists())",
          ".write": "auth != null && $owner === auth.uid"
        },
        "data": {
          ".read": "auth != null && ($owner === auth.uid || root.child('maps').child($owner).child('acl').child(auth.uid).exists())",
          ".write": "auth != null && ($owner === auth.uid || root.child('maps').child($owner).child('acl').child(auth.uid).child('role').val() === 'edit')"
        },
        "pilots": {
          ".read": "auth != null && ($owner === auth.uid || root.child('maps').child($owner).child('acl').child(auth.uid).exists())",
          "$uid": {
            ".write": "auth != null && ($owner === auth.uid || ($uid === auth.uid && root.child('maps').child($owner).child('acl').child(auth.uid).exists()))",
            "alts": {
              ".validate": "$owner === auth.uid || root.child('maps').child($owner).child('acl').child(auth.uid).child('multi').val() === true"
            }
          }
        }
      }
    },
    "access": {
      "$uid": {
        ".read": "auth != null && $uid === auth.uid",
        "$owner": {
          ".write": "auth != null && $owner === auth.uid"
        }
      }
    }
  }
}
  1. Onglet Données : copiez l'adresse en haut (elle finit par firebasedatabase.app).
  2. Roue dentée → Paramètres du projet → onglet Général : copiez la Clé API Web (commence par AIza).
  3. Même page, onglet Comptes de service → Générer une nouvelle clé privée. Un fichier .json se télécharge : gardez-le secret, ne le mettez jamais sur GitHub.

B. Cloudflare

  1. Créez un compte gratuit sur dash.cloudflare.com.
  2. Menu Compute (Workers) → Workers & Pages → Create → Start with Hello World. Nom : petit-poucet → Deploy.
  3. Edit code : effacez tout, collez le code du serveur (bouton ci-dessous), puis Deploy.
  4. Dans le Worker : Settings → Variables and Secrets → Add, quatre fois :
    ALLOWED_ORIGIN = l'adresse de votre carte sans le / final (ex. https://petit-poucet.github.io)
    EVE_CLIENT_ID = votre Client ID EVE
    FIREBASE_CLIENT_EMAIL = la valeur client_email du fichier .json (type Secret)
    FIREBASE_PRIVATE_KEY = la valeur private_key du fichier .json, de -----BEGIN à END PRIVATE KEY----- inclus (type Secret)
  5. Copiez l'adresse du Worker (ex. https://petit-poucet.votre-nom.workers.dev). En l'ouvrant, vous devez lire "configured":true.

C. Dans la carte

  1. Réglages : collez l'adresse du Worker, l'adresse Firebase et la Clé API Web, puis Enregistrer.
  2. Reconnectez-vous avec EVE si besoin : l'indicateur en haut passe à « Partagée · en direct ». Votre carte locale est envoyée automatiquement.
  3. Bouton Accès : tapez le nom in-game d'un joueur, choisissez son droit, Autoriser. Envoyez-lui le lien d'installation.
  1. Sur developers.eveonline.com, ouvrez votre application (ou créez-en une : Authentication & API Access).
  2. Autorisations : cochez le groupe esi-location (position, en ligne, vaisseau).
  3. Callback URL : l'adresse exacte affichée dans Réglages. En ligne, c'est votre adresse GitHub Pages, par exemple https://VOTRE-PSEUDO.github.io/carte-wh/.
  4. Copiez le Client ID dans les Réglages. Il est inclus dans le lien d'installation : vos joueurs n'ont rien à créer.
